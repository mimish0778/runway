# RUNWAY

「とりあえず 1 分だけ」から作業を始めるためのタイマーです。

いきなり作業に入ろうとすると腰が重いので、まず 1 分間の助走（IDLE）を挟み、終わったら「続ける」か「休む」かをその場で選びます。続けるなら作業時間の計測が始まり、休むなら 1 分休んでまた最初に戻ります。自分用に作ったもので、`index.html` をブラウザで開くだけで使えます。

考え方は [こちらの note 記事](https://note.com/awawa_adhd/n/n203716fd6e8b) を参考にしています。

## 流れ

```
STANDING BY ──START──▶ IDLE（1 分）──▶ 選ぶ ──KEEP GOING──▶ WORK（計測）
     ▲                     │            │                     │
     │                     └────────────┴──TAKE A BREAK───────┘
     │                                  ▼
     └─────────── 終了 / SKIP ──── BREAK（1 分）
```

1. **START** を押すと、1 分間の IDLE が始まります。何もしなくて大丈夫です。
2. 1 分経ったら **KEEP GOING**（作業する）か **TAKE A BREAK**（休む）を選びます。
3. WORK 中は経過時間がカウントアップされます。区切りたくなったら **TAKE A BREAK**。
4. BREAK は 1 分。時間が来るか **SKIP** を押すと STANDING BY に戻ります。

IDLE の途中でも「SKIP TO BREAK」で休憩に入れます。

## 画面の見方

- **SESSIONS** — 終えた WORK の回数
- **TOTAL TIME** — WORK の合計時間
- **TODAY** — 1 日 2 時間を目標にした進捗バー
- **LOG** — 直近の IDLE / WORK / BREAK の記録

右上の **SFX** で効果音のオン／オフを切り替えられます。

データはどこにも送信・保存されないので、ページを閉じるとリセットされます。
